## 动态网格

动态网格不是展示字段，而是实际改变挂单和止盈的执行参数。每次已完成分钟特征更新或有效事件到达时，策略重新计算并在满足迟滞与重报价条件后：

1. 用因果的已完成分钟 `sigma30`、波动率比率和趋势压力计算基础间距。
2. 用 JEV 事件压力乘数 `exp(event_pressure * 0.75)` 放大间距，再裁剪到 `0.5%` 至 `5.0%`。
3. 止盈距离设为当前间距的 `75%`；冲击或趋势压力升高时降低加仓倍数，并把加仓层数至少降到 `1` 层。
4. 网格变化达到 `25%` 或事件触发有效变化、且满足 `900 秒`重报价间隔后，清除旧的待成交加仓报价，按新间距重挂，并重算已有持仓止盈价。

最终配置：`vol_multiplier=10`、`minimum_spacing=0.005`、`maximum_spacing=0.05`、`profit_fraction=0.75`、`multiplier=1.1`、`max_adds=2`。

## JEV 作用

- JEV 输入为 ETHUSDT 专属、按月 walk-forward 校准的 NanoJev choice head，事件源为 BlockBeats public newsflash feed。
- 事件在 `available_ms + 5 秒` 后才可被策略使用；本次事件文件包含 `122,060` 条事件、`122,011` 个唯一投递秒。
- `p_breakout=p_up+p_down` 是短时方向突破压力代理，不是盈利概率或清算概率。
- JEV 主要提供连续事件压力：放大网格/止盈距离，并在压力超过阈值时禁止新的开仓、加仓和待成交报价；不把单条事件直接解释为平仓信号。
- 36 个月内 JEV 触发的有效动态网格更新为 `5,760` 次，事件压力风控覆盖 `49,408` 秒，事件平均可用延迟为 `5 秒`。
- 无 JEV 对照显示：12 个月收益为 `+705.484%`，24 个月为 `+20,769.196%`，36 个月为 `+237,600.099%`；启用 JEV 后分别为 `+1,545.720%`、`+17,461.736%`、`+228,966.403%`。因此本版本的主要收益驱动是动态网格和复利，JEV 的增量效果随区间变化，不能宣称 JEV 单独创造了全部收益。
